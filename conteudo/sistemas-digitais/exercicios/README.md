# ✏️ Exercícios de Sistemas Digitais

> [← voltar para Sistemas Digitais](../README.md)

**Nível:** 🟢 Iniciante

81 exercícios, 9 por assunto, com contexto de computação e **resolução passo a passo**. Eles seguem a ordem das [aulas](../aulas/): leia a aula, depois faça os exercícios do fácil ao difícil.

## 🧭 Como praticar

1. **Resolva no papel**, sem calculadora, como na prova.
2. **No site**, digite a resposta no campo e clique em **Conferir**. O corretor aceita vários jeitos de escrever (veja [como responder](../README.md#-como-responder-no-corretor)).
3. **Errou?** Refaça antes de abrir **Ver resposta**. Se errar de novo, leia a resolução e refaça sem olhar.
4. Cada página guarda o seu placar no navegador: volte depois e tente fechar todas.

| Nível | Exercícios | O que cobra |
| ----- | ---------- | ----------- |
| 🟢 Fácil | 01 a 03 | Aplicar o método direto, como nos exemplos da aula |
| 🟡 Intermediário | 04 a 06 | Juntar dois passos ou usar o método menos óbvio |
| 🔴 Difícil | 07 a 09 | Problemas com contexto, várias etapas e pegadinhas de prova |
